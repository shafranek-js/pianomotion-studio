## 3. P2: Play Along теряет ритм аккомпанемента

Область: playAlongEngine.ts, его tests и последовательная интеграция callback в PianoPlayer.tsx.

- Планировать каждый onset относительно начала текущего шага вместо синхронного запуска всех нот.
- Различать отдельные звучащие ноты и повторения одной высоты.
- Отменять события старого шага при stop/seek/переходе/смене режима/dispose; старые noteOff не должны обрывать новые голоса.

Приёмка: onset 0 и 0.5 секунды воспроизводятся последовательно; быстрый переход и повтор одной высоты не приводят к раннему noteOff; после отмены старые события не срабатывают.
