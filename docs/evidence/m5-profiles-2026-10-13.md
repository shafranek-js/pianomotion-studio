## 2. Key Architecture & Deliverables

### W034: Pianist Profile Model & Presets (`profiles/types.ts`, `profiles/defaultProfiles.ts`)
- Defined canonical built-in profiles:
  - `DEFAULT_PROFILE` (`default`): Mirrors desktop `pianists/default-copy.json`.
  - `SMALL_HANDS_PROFILE` (`small-hands`): 0.75x–0.85x bone lengths, smaller span, `stretch_bias = -0.4`, `weak_bias = 0.4`, `max_speed = 2.2`.
  - `VIRTUOSO_PROFILE` (`virtuoso`): 1.25x bone lengths, extended reach, `stretch_bias = 0.7`, `max_speed = 4.5`, `early_release = 0.15`.
  - `LEFT_DOMINANT_PROFILE` (`left-dominant`): Left hand priority for bass leads.
- Full type safety and runtime validation using `PianistProfileSchema.parse()`.

### W035: Application Settings Store (`settings/settingsStore.ts`, `settings/types.ts`)
- Persistent reactive settings store using `localStorage` (`handthesia:settings`).
- Manages user-configurable runtime options:
  - `keyStyle`: `"realistic"` | `"equal"`
  - `playbackSpeed`: `0.25 .. 2.0`
  - `masterVolume`: `0.0 .. 1.0`
  - `leadInSeconds`: `-2.0 .. 0.0`
  - `showFpsOverlay`: boolean
  - `showFingerLabels`: boolean
  - `showNoteNames`: boolean
  - `soundTimbre`: `"acoustic"` | `"bright"` | `"warm"`
  - `renderCapFps`: `0 | 30 | 60 | 120`

### W036: Legacy Profile Importer & Exporter (`profiles/legacyImporter.ts`, `profiles/profileStore.ts`)
- `importLegacyPianistJson`: Parses legacy desktop Python JSON configuration, applies safe defaults for missing parameters, sanitizes against prototype pollution (`__proto__`), enforces strictly positive bone lengths, and returns validated `PianistProfile`.
- `exportProfileToJson`: Standardized JSON serialization for profile backup and sharing.
- `ProfileStore`: In-memory and storage-backed profile repository supporting cloning, custom profile creation, and active profile selection, with deletion locks on canonical built-in profiles.

### W037: IndexedDB Schema v2 Upgrade (`storage/projectDb.ts`)
- Upgraded database version to `DB_VERSION = 2`.
- Preserved existing `projects` store and records without data loss.
- Added new stores:
  - `profiles`: stores custom pianist profiles keyed by `profileId`.
  - `settings`: stores application settings key-value pairs.
  - `session`: stores transient autosave recovery snapshots.
- Implemented structured error handling catching `QuotaExceededError` and raising `StorageQuotaExceededError`.

### W038: Autosave & Session Recovery (`storage/autosave.ts`)
- `AutosaveService`: Debounced session saving (default 400ms delay) to prevent UI thread thrashing during rapid edits.
- Stores `SessionSnapshot` containing current `projectId`, `document`, `fingeringPlan`, `activeProfileId`, and `viewMode`.
- Storage quota diagnostics via `getStorageQuota()` querying `navigator.storage.estimate()`.
- Integrated UI Modals: `ProfileModal.tsx` and `SettingsModal.tsx` with accessible dialog controls and live preview.
