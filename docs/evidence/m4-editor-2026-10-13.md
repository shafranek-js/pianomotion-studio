## 2. Key Architecture & Deliverables

### W028: High-Performance Canvas Piano Roll (`pianoRollCanvas.ts`, `pianoRollView.ts`)
- Pure HTML5 Canvas 2D implementation without DOM note bloat.
- Handles full 88-key piano keyboard (A0 pitch 21 to C8 pitch 108) with alternating white/black key background lanes.
- High-efficiency viewport culling: renders only notes within `[scrollX, scrollX + viewportWidth]` and visible pitch rows.
- Interactive controls:
  - Ctrl+Wheel / pinch centered zoom (`40 .. 600 px/sec`).
  - Middle-click drag / Space+drag / Shift+Wheel panning with bounds clamping.
  - Pixel-perfect hit testing and drag-to-select marquee box.
  - Alt-click / timeline click to seek transport.
- Lifecycle hygiene: explicit canvas cleanup in `destroy()` prevents DOM accumulation during React view mode switching.

### W029: Command Pattern Fingering Edits (`commands.ts`)
- Pure, immutable commands:
  - `createAssignHandCommand`
  - `createAssignFingerCommand`
  - `createToggleGlissandoCommand`
  - `createClearFingeringCommand`
- Every command preserves unaffected notes, bumps `inputRevision`, and records an ISO-8601 `modifiedAt` timestamp.

### W030: History Stack & Step-Entry Mode (`editorState.ts`)
- `EditorStateManager` manages a 50-step linear undo/redo history.
- Sequential step-entry mode advances selection to the next chronological note upon assignment.
- Keyboard shortcuts: `1..5` (fingers), `0/Del` (clear), `L/R` (hands), `G` (glissando), `Ctrl+Z` (undo), `Ctrl+Y` (redo), `ArrowLeft/Right` (navigation).

### W031: Ergonomics & Difficulty Engine (`difficulty.ts`, `DiagnosticsPanel.tsx`)
- Calculates piece ergonomics:
  - Hand stretch semitones (max semitone span per chord).
  - Note velocity / speed (maximum notes per second per hand).
  - Hand crossing count.
  - Awkward fingering count (e.g. thumb on black keys between white crossings, 4-5 trills).
  - Overall difficulty score (1.0 to 10.0) and tier (`Beginner`, `Intermediate`, `Advanced`, `Virtuoso`).
- Diagnostics panel displays categorized severity warnings with clickable "Jump to note" links.

### W032: Debounced Pyodide Re-Planning Bridge (`FingeringEditor.tsx`)
- Debounces fingering edits (300 ms) before triggering background Pyodide worker re-computation.
- Generates fingered SMF bytes in Python and re-runs kinematic planning (`performancePlan`, `motionPlan`).
- Outdated revision checks ensure race conditions from rapid typing are discarded.
